# Giọng đọc AI (ElevenLabs) + chọn giọng — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** "Đọc to" và ▶ câu ví dụ phát file audio ElevenLabs tạo sẵn theo 1 trong 5 giọng người đọc chọn, có "■ dừng", lỗi thì về giọng trình duyệt.

**Architecture:** `lib/audio/` gồm: danh sách giọng + đường dẫn file theo mã băm (dùng chung cho app, script, test), lựa chọn giọng trong localStorage (`useSyncExternalStore`), và **một bộ phát duy nhất** (`player.ts`) giữ "cái đang phát" theo khoá chuỗi. Mọi chỗ phát tiếng (đọc to, ví dụ, nghe thử, chữ bôi đen, từ tra) đi qua bộ phát nên luôn chỉ một thứ phát cùng lúc. Script `npm run audio` tạo file vào `public/audio/<giọng>/<mã>.mp3`.

**Tech Stack:** Next.js 16 App Router · React 19 · Tailwind 3 · TypeScript · vitest (`tests/`) · Playwright (`e2e/`) · ElevenLabs REST API · `tsx` (devDependency mới, chạy script đọc được alias `@/`).

**Spec:** `docs/superpowers/specs/2026-11-06-ai-voice-design.md` · mockup (đã chốt phương án A): `docs/superpowers/specs/2026-11-06-ai-voice-mockup.html`.

## Global Constraints

- Giọng (thứ tự hiển thị), tên, voice id ElevenLabs, mô tả, câu nghe thử:
  - `will` · Will · `bIHbv24MWmeRgasZH58o` · "nam · trẻ, thoải mái" · "Hi, I'm Will. Let's read this one together." — **mặc định**
  - `brian` · Brian · `nPczCjzI2devNBz1zQrb` · "nam · trầm, kể chuyện" · "Hi, I'm Brian. Let's read this one together."
  - `adam` · Adam · `pNInz6obpgDQGcFmaJgB` · "nam · chắc, rõ" · "Hi, I'm Adam. Let's read this one together."
  - `sarah` · Sarah · `EXAVITQu4vr4xnSDxMaL` · "nữ · điềm tĩnh" · "Hi, I'm Sarah. Let's read this one together."
  - `jessica` · Jessica · `cgSgspJ2msm6clMCkdW9` · "nữ · trẻ, tươi" · "Hi, I'm Jessica. Let's read this one together."
- Model `eleven_multilingual_v2`, định dạng `mp3_44100_64`, không gửi `voice_settings` (giữ mặc định của giọng, tốc độ 1.0).
- localStorage `tie:voice`; giá trị lạ / không đọc được → `will`.
- Chữ giao diện: nút "đọc to" ↔ "■ dừng"; nút desktop "giọng: Will ▾"; nhãn nút mobile `giọng đọc: Will`; tiêu đề ô chọn "giọng đọc"; nút nghe thử "▶ thử" / "■ dừng" (aria-label `nghe thử Will`); chân ô: "giọng AI tạo sẵn · chữ bôi đen và từ tra vẫn dùng giọng của máy".
- Phím: `s` = đọc to / dừng, `v` = mở chỗ chọn giọng (desktop; như `g`).
- Không in API key ra màn hình / log. Key đọc từ `.env.local` biến `ELEVENLABS_API_KEY`.
- Màu chỉ dùng token `lib/theme.css`; chạy cả theme sáng/tối; animation có `motion-reduce:`.
- Test trước, code sau. Mỗi task một commit `feat:`/`fix:`/`chore:` trên nhánh `task/ai-voice`. Cuối cùng `npm run verify` xanh.

## Review Focus

1. **Bấm "đọc to" hai lần thật nhanh / bấm `s` giữ phím (auto-repeat)** — không được phát chồng 2 lần hay kẹt ở "■ dừng" khi không có gì phát. Bộ phát phải bỏ qua sự kiện `ended`/`error` của lượt cũ đã bị thay. (Task 2: test "sự kiện của lượt cũ không đổi trạng thái lượt mới")
2. **File lỗi giữa chừng (mạng rớt) sau khi đã phát được vài giây** — `error` đến muộn: chỉ chuyển sang giọng trình duyệt nếu lượt đó vẫn là lượt hiện tại, và chỉ chuyển một lần (cả `play()` bị từ chối lẫn sự kiện `error` cùng đến). (Task 2)
3. **Trình duyệt không có Web Speech và file cũng lỗi** — nút phải về "đọc to", không kẹt "■ dừng". (Task 2)
4. **Mở trang lần đầu (server render) khi đã lưu giọng Sarah** — server vẽ "Will", trình duyệt đổi sang "Sarah" không gây lỗi lệch hình (hydration). Dùng `useSyncExternalStore` với snapshot server = `will`. (Task 1, Task 4: e2e không có lỗi console "hydration")
5. **Giữ phím mũi tên trong nhóm giọng** — mỗi bước đổi giọng → dừng phát; không được phát câu nghe thử tự động. (Task 4)
